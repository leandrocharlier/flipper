### Downloads

- **Windows x64:** `.exe` installer or portable `.zip` (extract the complete folder).
- **macOS:** `.dmg` or `.zip`, separately for **arm64** (Apple Silicon) and **x64** (Intel).
- **Linux x64:** `.AppImage` or portable `.tar.gz`.
- **SHA256SUMS.txt:** SHA-256 checksums for the downloadable applications.

Node.js is bundled. Android debugging requires Android SDK platform-tools/ADB and OpenSSL. Linux also requires libsecret. Windows packages are unsigned; macOS packages are ad-hoc signed and are not Apple-notarized.

### New: Mock API, powered by Mockoon 9.9

Select **Windows**, **Mac**, or **Linux** in Flipper's device selector, then **Mock API**. Existing profiles may need to enable the plugin in the Disabled section. The server runs on your computer; no Flipper SDK is required in the app that calls it.

- Import one or several files with a single **Import** button. Mockoon JSON and OpenAPI JSON/YAML are detected automatically; imported environment ports are preserved.
- Create multiple environments and start/stop each independently. New environments default to port **3000**; the port is editable alongside the server address and in Settings.
- Save configuration changes, then press the reload arrow to apply them to a running server. Native desktop imports watch their source files and show when a reload is needed; malformed edits retain the last valid configuration.
- HTTP/HTTPS with development certificates or custom PEM certificate/key, PFX, optional CA and session-only passphrases.
- The actual Mockoon engine provides routes, multiple responses, request rules, templates/Faker, latency, response files, proxying, data buckets/CRUD, callbacks and WebSocket routes. Advanced data/callback configurations use JSON editors; this is not a copy of every Mockoon visual editor or its Cloud features.
- Request/response viewer with in-memory history, plus Mockoon/OpenAPI exports and local environment persistence. TLS passphrases and admin API tokens are excluded from persisted configurations and exports. Other user-entered configuration, including headers and bodies, is saved as entered.
- No automatic server startup and no Mockoon Cloud connection. Importing or starting a mock does not automatically redirect an app's API requests.

See the [Mock API guide](https://github.com/leandrocharlier/flipper/blob/v1.0.0/desktop/plugins/public/mock-api/README.md).

### Android example and desktop maintenance

- The existing Android debug sample now has **Test Mock API HTTP** and **Test Mock API HTTPS** buttons. They show the response status/body and use the existing Network interceptor.
- A local setup helper creates example environments on ports **3000/3001** and a localhost certificate for HTTPS. Private keys remain in ignored local storage; only the public certificate enters the debug sample. Certificate and hostname validation remain enabled. See [sample instructions](https://github.com/leandrocharlier/flipper/blob/v1.0.0/android/BUILDING-16KB.md#local-mock-api-buttons-debug-sample).
- Host computers remain selectable when their plugins are disabled, including Linux. Desktop plugins are available without waiting for Android or iOS device discovery.
- Release workflow actions updated for the Node.js 24 runtime.
- All Logcat-style Logs features, Island Dark/Flipper Dark themes and previous desktop improvements remain available.

### Validation and scope

Publication requires the complete desktop Jest suite, backend lifecycle checks, packaging checks and the actual packaged-app smoke test to pass on Windows x64, macOS Intel, macOS Apple Silicon and Linux x64. Mock API tests exercise HTTP, HTTPS with PEM/CA and encrypted PFX, rules/templates, proxy/response files, imports, persistence and file watching. Packaged UI checks import multiple synthetic environments, start/reload/stop real servers and change listening ports. Existing skips and integration limits are documented in [TESTING.md](https://github.com/leandrocharlier/flipper/blob/v1.0.0/desktop/TESTING.md).

The Android example's HTTP/HTTPS buttons were additionally tested from Windows on an Android x86_64 emulator with 16 KB pages. These checks do not establish physical-device/iOS compatibility or exhaustive coverage of every Mockoon feature or Flipper plugin.

This is a **GitHub desktop release**. Android Maven dependencies remain a separate publication. Version 1.0.0 identifies this community desktop distribution; the embedded upstream protocol/plugin version remains 0.273.0 for compatibility.

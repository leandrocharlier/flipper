Independent community maintenance release by [Leandro Charlier](https://github.com/leandrocharlier/flipper), based on Meta Flipper. This is not an official Meta or Mockoon release. Original licenses and copyright notices are retained.

### Fixed

- Fixed the desktop permission policy that blocked the Network request/response body copy buttons. Clipboard writes are allowed only from Flipper's trusted main frame; renderer clipboard reads remain denied.
- Network now waits for the clipboard write before reporting success and displays an error if copying fails.
- Copying preserves the original body, including multiline text, Unicode and large JSON numbers, without parsing or reformatting it. Windows uses its native clipboard line endings.

### Validation

The release workflow requires the complete desktop Jest suite, TypeScript, Electron process/backend checks, native clipboard regression test and packaged application smoke test on Windows x64, macOS Intel, macOS Apple Silicon and Linux x64. Clipboard tests use synthetic data and verify both successful writes and denied reads. See [testing scope and existing limits](https://github.com/leandrocharlier/flipper/blob/v1.0.1/desktop/TESTING.md).

### Downloads and compatibility

- **Windows x64:** `.exe` installer or portable `.zip` (extract the complete folder).
- **macOS Intel / Apple Silicon:** separate `.dmg` and `.zip` downloads for x64 and arm64.
- **Linux x64:** `.AppImage` or portable `.tar.gz`.
- **SHA256SUMS.txt:** SHA-256 checksums for the downloads.

Node.js is bundled. Android debugging requires Android SDK platform-tools/ADB and OpenSSL; Linux also requires libsecret. Windows packages are unsigned. macOS packages are ad-hoc signed and are not Apple-notarized.

This is a desktop-only update. Android Maven artifacts remain at **1.0.0** under `io.github.leandrocharlier.flipper`; no Android SDK upgrade is needed for this fix. The embedded upstream protocol/plugin version remains **0.273.0** for compatibility. Mock API, Logs and the other existing desktop features remain available.

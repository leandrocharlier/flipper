Independent community release maintained by [Leandro Charlier](https://github.com/leandrocharlier/flipper), based on Meta Flipper 0.273.0. This is not an official Meta release. The original MIT license and copyright notices are retained.

### Downloads

- **Windows x64:** `.exe` installer or portable `.zip` (extract the complete folder).
- **macOS:** `.dmg` or `.zip`, separately for **arm64** (Apple Silicon) and **x64** (Intel).
- **Linux x64:** `.AppImage` or portable `.tar.gz`.
- **SHA256SUMS.txt:** SHA-256 checksums for the downloadable applications.

Node.js is bundled. Install Android SDK platform-tools/ADB and OpenSSL to connect native Android apps. Linux also requires libsecret. The Windows packages are unsigned; macOS packages use ad-hoc signing and are not Apple-notarized. The operating system may require explicit approval to open this community build.

### Changes

- Standalone desktop window with an isolated renderer and automatic backend shutdown.
- Logcat-style selectable text, complete multiline messages and consistent line spacing.
- One filter field with suggestions for package, process, tag, message, level, PID and TID.
- Reading position survives filter edits, cleared searches and intermediate empty results.
- Imported sessions stay selected when live devices or apps connect or disconnect.
- Imports wait for device plugins to finish loading, preserving logs imported during startup.
- Configurable Logcat Format, saved locally; Soft wrap starts disabled.
- Optional Island Dark theme alongside Flipper Dark; bundled JetBrains Mono font.
- Package metadata in new exports and conservative recovery from explicit Android lifecycle records in legacy imports.
- Updated desktop HTTP, WebSocket and archive dependencies, plus Windows startup fixes.

### Scope and licenses

This release publishes desktop applications only. Android dependencies on Maven will be published separately after their publishing validation. Desktop improvements do not require updating the Android SDK at the same time. Version 0.3.0 identifies this community desktop distribution; the embedded upstream protocol and plugin version remains 0.273.0 for compatibility.

Each build runs the complete desktop Jest suite (core, server and public plugin tests), backend lifecycle checks and a packaged-app smoke test using synthetic data on its native OS. Existing skipped tests and integration gaps are documented in [desktop/TESTING.md](https://github.com/leandrocharlier/flipper/blob/v0.3.0/desktop/TESTING.md). Android connectivity has additionally been tested on Windows; these checks do not establish iOS debugging compatibility or complete end-to-end coverage of every plugin.

Application resources include the Flipper MIT license, community-fork NOTICE, third-party dependency notices, Node.js notices, Electron/Chromium notices and JetBrains Mono's OFL-1.1 license. Component licenses remain applicable to their respective components.
